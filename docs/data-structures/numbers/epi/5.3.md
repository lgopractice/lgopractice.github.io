# Reverse bits

Write a program that takes a 64-bit word and returns the 64-bit word consisting of the bits of the input word in reverse order.

```java
public static long reverseBits(long x) {
  // Fill here.
}
```

## Solution

??? "Implementation"
  
    ```java
    public static long reverseBits(long x) {
      long y = 0L;
      for (int i = 0; i < Long.SIZE; i++) {
        y = (y << 1) | (x & 1);
        x >>>= 1;
      }
      return y;
    }
    ```
