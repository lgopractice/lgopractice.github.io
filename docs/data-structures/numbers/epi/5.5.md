# Compute x × y without arithmetical operators

Write a program that are allowed to use are multiplies two integers.

```java
public static long multiply(long x, long y) {
  // Fill here.
}
```

## Solution

??? "Addition"
  
    Your first instinct is to go for an addition function which can be called repeatedly. This is the canonical half-adder approach. It eliminates the need for masks and independent loop counters by continually reducing the problem until there is nothing left to carry over.
    
    ```java
    private static long add(long x, long y) {
      while (y != 0) {
        long carry = x & y;
        x = x ^ y;
        y = carry << 1;
      }
      return x;
    }
    ```
    
    When the function starts $y$ is the second number we want to add. But after the first loop, it gets absorbed into $x$ via the XOR operation.
    
    From that point onwards, $y$ gets repurposed as container for unresolved carries.
    

??? "Multiplication"
    
    ```java
    public static long multiply(long x, long y) {
      long multiplication = 0;
      while (x != 0) {
        if ((x & 1) != 0) {
          multiplication = add(multiplication, y);
        }
        x >>>= 1;
        y <<= 1;
      }
      return multiplication;
    }
    ```
