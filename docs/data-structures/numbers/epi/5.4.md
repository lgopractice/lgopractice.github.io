# Find the closest integer with same weight

Define the weight of a non-negative integer $x$ to be the number of bits that are set to $1$ in its binary representation. For example, since 92 in base-2 equals $1011100_2$, the weight of $92$ is $4$.

Write a program which takes as input a non-negative integer $x$ and returns a number $y$ which is not equal to $x$, but has the same weight as $x$ and their difference, $|y - x|$, is as small as possible. You can assume $x$ is not $0$, or all $1$s. For example, if $x = 6$, you should return $5$.

```java
public static long closestIntSameBitCount(long x) {
  // Fill here.
}
```

??? "More details"

    There are two forms $x$ can take:
        
    1. $x$ ends in a trail of 0s, e.g. $x = aaaa1000$
    : in which case our solution would be $y = aaaa0100$
    
    2. $x$ ends in a trail of 1s, e.g. $x = aaaa0111$
    : in which case our solution would be $y = aaaa1011$
    

## Solution

??? "Finding which form x takes"
  
    Let's start with a bit of bit magic:
      
    ```
         x = aaaa1000
        ~x = āāāā0111
        -x = ~x + 1
           = āāāā1000 
       
    x & -x = 00001000
    ```
    
    That is $x \ \& \ -x$ gives us the mask for the rightmost set bit. We can use it to check which form does $x$ take; does it trail in 0s or 1s.
    

??? "When $x$ ends in trail of 0s"
    
    We already has a mask $r$ for the rightmost set bit. `r | (r >>> 1)` gives us a new mask that can be xor'd with $x$ to shift the rightmost set bit to further right.
    
    ```
        x = aaaa1000
        r = 00001000
        m = r | (r >>> 1) 
          = 00001100
      
    x ^ m = aaaa0100
    ```    
    
??? "When $x$ ends in trail of 1s"
    
    We can find a mask for the righmost unset bit like this.
    
    ```
             x = aaaa0111
            ~x = āāāā1000
           x+1 = aaaa1000
    
    ~x & (x+1) = 00001000
    ``` 
    
    The rest is the same as previous approach to move this rightmost unset bit further right.
    
    ```
        x = aaaa0111
        r = 00001000
        m = r | (r >>> 1)
          = 00001100
       
    x ^ m = aaaa1011
    ```
  
??? "Implementation"
  
    ```java
    public static long closestIntSameBitCount(long x) {
      long r = x & -x; // (1)
      if ((r & 1) != 0) { // (2) 
        r = ~x & (x + 1); // (3)
      }
      long m = r | (r >>> 1);
      return x ^ m;
    }
    ```
    
    1. Mask for rightmost set bit.
    2. $x$ trails in 1s
    3. Update $r$ to be the mask for rightmost unset bit instead.
