# Computing the parity of a word

The parity of a binary word is $1$ if the number of $1$s in the word is odd; otherwise, it is $0$. For example

- the parity of $1011$ is $1$
- the parity of $10001000$ is $0$

```kotlin
}
```

## Solutions

??? "Brute force"
  
    We know from [Bit tricks](../bit-tricks.md) that the following expression unsets the rightmost set bit in a number $n$.
    
    $$
    n \ \& \ (n-1)
    $$
    
    We can perform this repeatedly until there are no more bits to unset.
    
    ```kotlin
    fun parity(x: Long): Short {
      var n = x
      var parity = 0
      
      while (n != 0L) {
        n = n and (n-1)      // unset rightmost set bit of n
        parity = 1 - parity  // flip between 0 and 1
      }
      return parity.toShort()
    }
    ```
    
    Complexity of this approach is $O(n)$ where $n$ is the word size.
    
??? "Lookup table"
  
    The previous approach is fine, but we can speed up significantly by directly finding the parity of a chunk instead of finding it bit by bit.
    
    We run the previous brute force solution over the all possible number in range $[0, 256)$. We save these results in the method `lookup`
    
    ```kotlin
    private fun lookup(word: Long): Int = when(word.toInt()) {
      0, 3, 5, 6, 9, 10, 12, 15, 17, 18, 20, 23, 24, 27, 29, 30, 33, 34, 36, 39, 40, 43, 45, 46, 48, 51, 53, 54, 57, 58, 60, 63, 65, 66, 68, 71, 72, 75, 77, 78, 80, 83, 85, 86, 89, 90, 92, 95, 96, 99, 101, 102, 105, 106, 108, 111, 113, 114, 116, 119, 120, 123, 125, 126, 129, 130, 132, 135, 136, 139, 141, 142, 144, 147, 149, 150, 153, 154, 156, 159, 160, 163, 165, 166, 169, 170, 172, 175, 177, 178, 180, 183, 184, 187, 189, 190, 192, 195, 197, 198, 201, 202, 204, 207, 209, 210, 212, 215, 216, 219, 221, 222, 225, 226, 228, 231, 232, 235, 237, 238, 240, 243, 245, 246, 249, 250, 252, 255 -> 0
      else -> 1
    }
    ```
    
    Next we call this as subroutine to find the parity of a 32-bit integer byte by byte.
    
    ```kotlin
    fun parity(x: Long): Short {
      var n = n
      var parity = 0
      while (n != 0L) {
        // 255 is our mask here for extracting the least significant 8 bits.
        parity = parity xor lookup(n and 255)
        n = n ushr 8
      }
      return parity.toShort()
    }
    ```
    
??? "Intended solution"
  
    Notice a pattern here:
    
    - parity of `00 => 0`
    - parity of `01 => 1`
    - parity of `10 => 0`
    - parity of `11 => 0`
    
    That is, parity of two bits $a$ and $b$ is $a \oplus b$. We can leverage this to repeatedly fold the interger into itself.
