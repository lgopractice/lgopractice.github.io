# Swap bits

Given a number $x$, swap the bits at given positions $i$ and $j$.

```java
public static long swapBits(long x, int i, int j) {
  // Fill here.
}
```

## Solution

??? "Explanation"
  
    There are 4 scenarios to consider:
    
    - $xxxx1xxxx1xxxxx$: do nothing
    - $xxxx0xxxx0xxxxx$: do nothing
    - $xxxx1xxxx0xxxxx \Leftrightarrow xxxx0xxxx1xxxxx$
    
    Notice that we can achieve the last with a simple mask $xxxx1xxxx1xxxxx$, since:
    
    - $1 \oplus 1 \rightarrow 0$
    - $0 \oplus 1 \rightarrow 1$

    
??? "Implementation"
  
    ```java
    public static long swapBits(long x, int i, int j) {
      long maskI = 1L << i; // (1)
      long maskJ = 1L << j; // (2)
      if (((x & maskI) >>> i) == ((x & maskJ) >>> j)) return x;

      long mask = maskI | maskJ; // (3)
      return x ^ mask;
    }
    ```
    
    1. our $xxxx1xxxxxxxxxx$ mask
    2. our $xxxxxxxxx1xxxxx$ mask
    3. our $xxxx1xxxx1xxxxx$ mask
